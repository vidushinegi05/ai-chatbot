# AI Chatbot

## Project Overview

AI Chatbot is a simple web-based chatbot application built using React and API integration. The project focuses on creating a clean chat interface where users can type messages, send them to an API, and receive responses in a conversational format.

The main goal of this project was to understand how frontend applications interact with APIs and how user input can be handled, processed, and displayed in real time.

## Problem Statement

Many modern web applications use chatbot-style interfaces for support, search, recommendations, and AI-based assistance. This project was built to understand the basic structure of a chatbot UI and how frontend applications communicate with external APIs.

## Tech Stack

- **Frontend:** React.js
- **Language:** JavaScript
- **API:** REST API integration
- **Styling:** CSS3
